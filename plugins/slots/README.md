# slots

**Purpose** — one-armed bandits. `spin` at a machine flagged `flags.slot_machine` deducts the bet, rolls three weighted reels, renders an ASCII reel window and pays out on matches.

House-favoured RTP, and **reusable for any slot furniture** — the machine is content, the maths is here.

## Commands
- `spin [bet]` / `slots`
