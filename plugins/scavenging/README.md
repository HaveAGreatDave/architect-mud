# scavenging

**Purpose** — a perpetual, posture-based search. Zones opt into a reusable loot table; the **Scavenging** skill gates what you find; per-zone stock **depletes and lazily replenishes**, so a picked-over street stays picked over for a while.

## Commands
- `scavenge`

## The check
**2d8 − 2d8** against the skill — a bell curve, so most attempts are unremarkable and the tails are rare in both directions.

## Schema reuse
The table format here is the one **fishing** and **mining** also use.
