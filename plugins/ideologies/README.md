# ideologies

**Purpose** — where you stand with the four orders, and which way you lean. Owns the read-out and the three dialogue Actions that move it.

## Commands
- `ideologies` / `rep` — standing, plus your stance-and-path lean.

## Actions registered
- `ADJUST_REPUTATION` — over `player_ideology_rep`.
- `ADJUST_STANCE` — the redeem/renounce axis.
- `ADJUST_PATH` — the machine / flesh / mind / human path affinities.

All three are **dialogue-authorable**, which is the point: an ideology moves because of something you said, not a menu you opened.
