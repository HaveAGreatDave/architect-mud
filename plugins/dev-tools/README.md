# dev-tools

**Purpose** — admin-only utility verbs. Not part of the game; the switches you reach for while building it.

## Commands
- `heal` — patch yourself up.
- `makeitrain` — credits.
- `lettherebelight` — light a dark room.
- `weatherevent` — force a weather event.
- `testaccolade` — fire an accolade.
- `dresscyd` — a bespoke fixture.

All are admin-gated.
