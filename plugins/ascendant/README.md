# ascendant

**Purpose** — campus mechanics for the Ascendant Stronghold. Just The Threshold: a move gate on the inner ring that turns away anyone who has not been cleared. The Stronghold itself is content; this is the one law that makes its geography mean something.

## Commands
None — it is a move gate, not a verb.

## Dependencies
- **ideologies** — clearance is read off ideological standing.

## Extension points
None.
