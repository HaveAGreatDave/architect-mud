# trade

**Purpose** — the two-sided trade window, and the default interface for exchanging items **and** credits safely. `trade <player>` opens a shared two-panel window; each side stakes what they are offering.

## The anti-scam rule
**Any change to either side unlocks both sides.** The atomic swap only happens once **both** have locked in against the exact contents they can see. You cannot swap the goods out after the other party has agreed.

## Commands
- `trade <player>` — open the window.
- `tradeoffer` · `traderetract` · `tradeready` · `tradecancel`

The buttons drive these same commands, so anything the UI can do you can also type.
