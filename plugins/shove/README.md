# shove

**Purpose** — moving a body that does not want to move, or cannot. Shove or drag a player, NPC, corpse or sleeper into an adjacent room through a contested **brawn-vs-weight** check.

## Commands
- `shove <target> <dir>` / `drag <target> <dir>`

## Discovery gap (known)
Directional, with no tag anchor, and player/NPC examine prints only talk and attack. Structurally the same gap as `knock`.
