19 Jun

Day One

A room, and a verb. Nothing else exists out there. "Heckmud version 0.01"

Fifteen commits before midnight. Four of them called Update index.html.

20 Jun

Two Hands on One File

Merge, revert, merge back. "I really think john akerson is a rube." Push anyway.

The day CLAUDE.md was born, and the day the CSS was split out, reverted, and split out again.

21–30 Jun

The Body Keeps Score

Hunger, thirst, and rads. Armor sums from every source. Corpses on the floor.

Combat gets body parts and typed soak. The dead start leaving something behind.

1–7 Jul

Git Becomes the World

The seed script is dead. One JSON file per thing — a push is a deploy.

CODEX cutover, 8 July. CONTENT_READONLY on prod: the database stops being an author.

8–18 Jul

The Sky Opens

Stall horn. Redrock blur. The ground was always data — now it rushes up.

The banded flight model is abandoned for one continuous client-sim/server-reconcile loop.

19–25 Jul

Round Trips

"less queries for the queeries" — the furniture cache learns to hold its breath.

Read tiers get written down. Hot paths stop asking Postgres anything.

22–31 Jul

A Pan Is Not a Dish

Dry pasta refuses. Water goes in as a row, not as a number.

Cooking ships. 47 recipes, and the rule that a liquid answers every question about the pan and none about the dish.

1–7 Aug

Rooms That Remember

The bank had four rooms and no front door for a week. Someone walked the map.

Map audits, jail cells that lock, a shop that closes around you, an NPC who introduces himself exactly once.

8–13 Aug

Flesh, Chrome, and the Quiet Kind

Nothing is baked in. Read the number at read time — you can still go back.

Mutations, augments, nullcraft, psionics. Four answers to the same question, none of them written into players.

14 Aug

Now

A title screen glows. Out the windshield, a highway. Hold the line. Drive on.

The Long Haul, phase one. The road between regions is something you steer, not something you skip.

Fifty-seven days. Every haiku above is a real week of commits.
The corridor synthesises zones, never render cells.
