The State of the Union01

My fellow contributors: we stand at a moment of great opportunity, by which I mean a great many things are half-built and nobody has died of it yet. In thirty-nine days this repository went from empty to a functioning city with weather, jail, a casino, two professional sports leagues, an aviation simulator, a hygiene substrate, and a public library stocked exclusively with books whose copyrights expired. That is not a normal thing to have done. It is also not a normal thing to maintain.

Where the mass actually is02

The project describes itself as a Node server with a vanilla client. The tape measure disagrees about which of those is the project. The client is the single largest body of code in the repo — windshield, tablet OS, cockpit and aircraft renderers alone account for more than 24,000 lines, which is to say the "text MUD" ships a flight simulator with volumetric clouds.

The good news buried in that chart: plugins outweigh the server two to one. The engine-vs-plugin boundary is not an aspiration in a proposal doc, it is the actual shape of the code. Combat, survival, economy, flight, broadcast, crime — all of it sits outside the engine, which means the engine can still be reasoned about by one person on one afternoon. That is the single most valuable structural fact in this report.

A single broadcast/index.js is 7,953 lines. It is one file. It contains channels, playlists, VINE scripts, NPC hosts, camera feeds, five live-assembled show modes, and two entire sports leagues. It is load-bearing television and it is one file.

Where we made strides03

Content left the database

The CODEX cutover is the most consequential thing that shipped this period and the least exciting to look at. World content is now one JSON file per entity in git — roughly 11,100 of them — and a push to main is the deploy: schema first, content additively, backed up, regress-gated. Before this, "what is in the world" was a question you answered by querying production. Now it is a question you answer by reading a diff. Every other item on this list is downstream of that.

The substrate pattern held

Durability, relationships, hygiene, senses, cleaning — five systems shipped this period that all follow the same shape: an engine substrate that is sync and query-free by contract, with plugins contributing on top. getRelation, hygieneOf, and wear never touch the database at call time. That is the discipline that lets a room description gather smells, an NPC recall your face, and a rifle degrade mid-swing without any of it costing a round trip to Neon. It is also why the game will still be responsive at ten concurrent players instead of one.

The regression gate is real

90 of 108 plugins ship their own regress.js. The suite boots the world, sweeps every manifest against the live registries, and drives real commands through the dispatcher. This is unusually good coverage for a hobby project of this age, and it is the only reason the deploy pipeline is trustworthy enough to be a git push.

The eighteen without: audio, bulletin, butchering, clothing-wetness, container, debug, emergency, fillable, food, interactions, knock, library, lighting, mutations, scavenging, shove, water, zone-validator. Several of those are trivial. scavenging, food, lighting, library and interactions are not — they are systems players touch constantly, and they are currently defended by vibes.

The weather can kill you, by name

Extreme weather is complete through step 7d. Acid rain applies a corroding effect scaled by how much of you a waterproof garment actually covers, eats your gear through the ordinary durability path, and outlasts shelter until you wash. The ion storm blacks out the grid, fries unshielded carried electronics durably — a bench repair, not a new system — and knocks out chrome transiently in memory rather than bricking a paid-for augment. Both carry a full presentation kit: forecast icons, weather FX, audio beds, flight-canopy hazards, news headlines per phase, and radio beats. A hero day is knowable a week out; the hour it lands is not.

You can walk between regions

Overland void travel is built, not planned: the voidwalking plugin ships five verbs and hangs off the movement.edge seam, generating transient waste rooms off a region's rim that never touch the database. Reaching The Reach on foot is a survival gauntlet rather than a locked door, which is the whole reason the airfield network has stakes. This report's first edition filed it under design; it has its own regress suite.

VINE authors the branching content

Quests, dialogue trees, enemy behaviour trees and broadcast scripts are all authored in one graph editor with a shared Suite front page and a schema per family. The quest schema converts a quests row to a prerequisite DAG and back, so objectives and rewards are drawn rather than typed. This report's first edition claimed there was no visual quest editor; that came from a stale README bullet, which has since been deleted.

Documentation that outranks memory

24,632 lines of docs across 54 files, with an explicit convention that (as built) beats design intent. The docs are load-bearing enough that CLAUDE.md tells you to read the relevant one before touching a system. Most projects this age have a README and a lie.

A prototype parked at the point it proved its approach is not debt — it's a spike that did what spikes are for. The whole thing is one self-contained file to delete if the answer is no.

The three that actually matter

  • The manual post-deploy step. A deploy that isn't finished until a human remembers to run a script against production isn't a deploy, it's a ritual. Every other piece of the CODEX pipeline is automated and gated. This one gap will eventually ship a city with the lights off, and it will happen on the day nobody is watching.
  • The uncommitted backlog. Ten entangled projects in one dirty tree means no single change can be reverted, reviewed, or bisected. The regression suite is excellent and cannot help you here, because it can only test what you managed to commit.
  • Content mass versus content depth. 5,822 zones against 169 NPCs, 63 quests, and 39 enemies. The world is enormous and thinly populated — the map has outrun the reasons to walk it. The next expansion pass probably shouldn't be a map.
Ratio worth staring at: 34 zones per NPC · 92 zones per quest · 149 zones per enemy. A player can walk for a very long time in a very beautiful place and meet nobody.

In conclusion05

The foundations are, genuinely, better than they have any right to be at thirty-nine days old: a clean engine/plugin boundary that the line counts confirm rather than contradict, content in git with a gated deploy, a real regression suite, and a documentation habit that survives contact with the code. The rare failure mode for a project like this is architectural, and that failure did not happen here.

What is at risk is narrower and more ordinary. There is more world than there is life in it, more shipped systems than committed ones, and one manual step standing between a push and a working city. None of those are hard problems. They are just the unglamorous ones, and this report notes with regret that they do not get done by being noted in a report.

The state of the game is strong. Commit your tree.
