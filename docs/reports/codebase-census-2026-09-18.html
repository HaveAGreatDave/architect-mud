The named systems platform vs. game

Four of the five names below are the platform; the fifth is the game built on it. The split is load-bearing — anything that hardcodes Coldwater into an engine or client file is a thing a second game would have to unpick.

THOMAS

The Hypermedia Online Multiplayer Adventure System

The client and the engine. Everything under client/, server/engine/, the dev panel, the plugin loader and the CODEX pipeline.

47,736 lines engine · 34,565 dev panel

GLASS

Geometry, Lights, Aircraft, Streets & Structures

The 3-D renderer. CPU on a plain 2-D canvas, with a WebGL2 pass under it since September. Two viewers: a cockpit canopy and a truck windscreen.

35,478 lines core · 8,241 GL · 209 models
