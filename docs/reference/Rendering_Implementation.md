# Environmental Rendering Guidelines

## Philosophy

Render the real Architect world, not generic scenery.

Use: - room descriptions - district names - zone names - neighboring
tiles - map topology - terrain metadata - landmarks

Treat the city as one continuous landscape.

## Districts

Infer broader neighborhoods before rendering. Create coherent
commercial, industrial, residential, airport, forest and waterfront
districts.

## Biomes

Use rendering-only categories such as: - Downtown - Residential -
Commercial - Industrial - Airport - Forest - Waterfront - Marsh -
Agriculture - Military

## Mode 7

Blend the existing renderer with Mode 7-inspired perspective: -
perspective scaling - horizon compression - distance haze - affine-style
projection - textured ground - object scaling

Do not literally recreate Mode 7.

## Buildings

Create reusable aerial archetypes including warehouses, offices,
apartments, factories, hospitals, hangars, power stations, storage
yards, parking garages and towers. Add roof variation, shadows, pavement
and loading areas.

## Terrain

Improve grass, dirt, concrete, asphalt, water, forest, beaches, runways,
taxiways and rocky terrain.

## Roads

Render connected transportation networks with intersections, bridges and
parking.

## Airports

Distinct runways, taxiways, aprons, hangars, markings and lighting.

## Goal

Experienced players should recognize districts from the cockpit before
looking at the minimap.
