1. The regression suite: tests/regress.js

Boots the world and all plugins without a server, then:

  • checks every plugin.json against the live registries (declared commands and hooks are actually wired);

4. Drift between the two lists

5. Outside the chain

  • Modelshop benches (npm run modelshop, :5181): __glFrame, __glFidelity, __glLeak, __glSea*, __glWhere and others. Pixel and timing measurements no headless gate can make, since every headless harness installs a GL hook that returns null.
  • Reports: models:quality, models:survey, models:diff, and the --report forms of many gl:* scripts.
  • Content: content:lint also runs before every content:import; db:vine-lint checks VINE graphs.
  • Scheduled: usage-watch.yml (Neon/Render budget) and sync-commits.yml.

Adding a check

  1. Put it in the pretest:regress chain itself. That's what the push runs.
  2. If it's a GLASS gate, add it to shapes:smoke too so a hand run matches.
  3. For a new plugin or verb, add plugins/<name>/regress.js.
