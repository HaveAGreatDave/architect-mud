# ORACLE recording script
#
# Read by one speaker, for fitting ORACLE's formant and timing tables to a real voice
# (the step after docs/proposals/oracle-naturalness.md: targets fitted from recordings).
# 286 lines, about 15 minutes with pauses. Part 3's sentences are written for this
# script, not the Harvard lists; they cover the same ground (every sound, questions,
# lists, commas, short fillers).
#
# HOW TO RECORD
# - A quiet room with soft things in it (a closet of clothes is good, a bare kitchen bad).
# - The same mic at the same distance, a hand's width or two, the whole way through.
# - WAV, 44.1 or 48 kHz, 16-bit or better. Turn OFF noise suppression, auto gain and
#   any "voice enhancement"; phone and call apps add them by default.
# - Plain voice, normal steady pace, not acting. Leave about a second between lines.
# - One file per part is ideal: part1.wav, part2.wav, part3.wav, part4.wav. You don't
#   split anything; the pauses between lines do that, and the fitting tool matches each
#   piece to its line. Stopping partway is fine: start a new file and name it by the
#   line it begins at (part1.wav, then 071.wav if you stopped after line 070). Use the
#   same room, mic and distance each time, and warm your voice up for a minute first.
#   WAV or FLAC; never MP3, M4A or a voice-memo app's own format.
# - Read the lines in order with a clear pause, about a second, between them. Stumbled?
#   Pause, and read that line again from the start: the last reading is the one kept.
# - Read every numbered line out loud exactly as written, the whole line: for
#   "Say heed aloud." you say all three words. Don't read the numbers, anything in
#   [brackets] (a rhyme to help with a made-up word), or the lines starting with #.
#
# PART 1: VOWELS IN A FRAME
# Each vowel in "h_d", then after a b/p, d/t and g/k sound, in "Say ___ aloud."
# ("aloud" starts with a vowel, so the word's last sound releases cleanly into it,
# and every word sits mid-sentence at the same pace).
# Lines repeat on purpose: two or three readings of a word average out the wobble in
# any one. Read each the same way, not more carefully each time.
# Say every word as you normally would. Some people say "hod" and "hawed" alike,
# or "cot" and "caught" alike: that's fine, don't force a difference.
# The h_d words that aren't real words rhyme with the word in brackets.
