  // ── HALCYON FIELDS (docs/proposals/coldwater-infill.md's sibling quarter) ──────
  // ⚠ THE WHOLE QUARTER IS ONE MATERIAL ARGUMENT, AND IT IS NOT A TASTE ONE. Halcyon Fields
  // is the Ascendant campus expanding south, developed by the people who built The Spire and
  // Halcyon Towers, so it is faced in what they face things in: curtain glass over brushed
  // chrome, no grime, no coursing, no brick anywhere. The first cut of this quarter was
  // limestone, stock brick and works green, and it read as a Victorian civic district that had
  // wandered into the wrong city — correct for a waterworks and wrong for THIS waterworks,
  // which exists to keep a thirty-storey machine cold.
  //
  // ⚠ THE FAMILY IS THE FEATURE, NOT THE TRIPLE. A chrome colour in STONE_WALL still courses
  // like ashlar and still punches a tenement window grid, so retuning the RGB alone buys pale
  // masonry. Three families carry the quarter: GLASS_WALL for anything with storeys behind it
  // (floor-plate striping and a sky sheen instead of a grid), PLAIN_WALL for the chrome
  // panelling between and around them (flat, unwindowed — the family's own comment calls it
  // structure, and a seamless clad panel is exactly that), and METAL_WALL only where the thing
  // genuinely is rolled or pressed steel: a fan cowl, a gasholder drum, a louvre bank, a tank.
  //
  // The palette is deliberately narrow — four values of chrome and two of glass, reused across
  // fifteen buildings — because an estate built in one campaign by one developer looks like one
  // thing, and every district in Coldwater that reads as a district reads that way for the same
  // reason. The variety is in the SILHOUETTES, which is where variety survives fog.
