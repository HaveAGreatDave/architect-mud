Fix order

  1. Escape the two stored-XSS paths. Escape origin_fragment on write in apiUpdateOwnProfile, and again in describePlayerAppearance so existing rows are covered. Escape the yell text in propagateYell and in the yeller's own echo. Then grep for any other type:'output' broadcast that interpolates raw player text.
  2. Fix the two lazy-loading regressions. Make cabinAudio and flightSimFireworks no-ops until the cockpit has loaded, and make close* wait for a pending load instead of dropping.
  3. Close the open GET routes. Put auth on /players/online, /zones, and the flight, broadcast and audio GETs.
  4. Stop storing the password. "Remember me" should keep a revocable token, not mud_remember_pass.
  5. Guard boot-time storage reads in main.js (lines 104 and 455), and strip the query string (and percent-decode) in the static server.
  6. Add a CSP and basic security headers, once inline handlers like [spoiler]'s onclick are moved out.
  7. Decide the deploy questions: which X-Forwarded-For hop to trust (plus a per-account login limit), TLS verification for Neon, and CORS.
