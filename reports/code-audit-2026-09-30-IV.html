Fix order

  1. Close the presence XSS. Make /admin/presence staff-only and use the token's own handle instead of the posted one; escape handles in the Who and Players panels anyway.
  2. Stop looting the living. lootall and lootid should fall back only to a sleeping or offline player, checked against the live world, not the saved row.
  3. Make item moves race-safe. Delete the source with RETURNING and only add to the target if the delete hit (or run both in a transaction with the row locked); the same for give, loot and the drop split. Serialising each player's commands would close the whole class.
  4. Check ownership at the point of the move: trade's moveItem, storefront supply (lock the row inside the transaction), pour (one transaction), and the shop's furniture branch (stock and shelf).
  5. Cap and dedupe panel_data fields; limit /spawn to dev and admin and validate its quantity.
  6. Client: key whisper history by player and clear it on sign-out; guard the main.js d-pad storage reads; fix the pre-paint remember-me check, the sign-out storage write, and spray-shelf loading.
  7. Then the minors: the ATM races, the bounty transaction, acceptpay's room check, whole-number shop quantities, and the load-cost items.
